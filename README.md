Welcome to the Cloudflare Workshop!

Commands to complete step  1:

1) Run `npm create cloudflare@latest` in terminal
2) Create your application in the directory `rag-ai-tutorial`
3) Select `Hello World Example`
4) Select `Hello World Worker`
5) Select `JavaScript`
6) Select `yes` for "Do you want to use git for version control?"
7) Select `no` for "Do you want to deploy your application?"
8) Run `cd rag-ai-tutorial` in terminal
9) Run `npx wrangler dev --remote` in terminal
10) Press `b` to open your app in the browser
